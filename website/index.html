DESIGNER FIRST

Windows 앱은,
폼 디자이너와 함께.

프레임워크별 컴포넌트와 배치 방식을 구분합니다. 메뉴와 레이아웃, 편집 영역과 상태 표시줄을 네이티브 앱의 구성에 맞게 설계합니다.

Visual StudioWinForms · WPF · WinUIMenuStrip · DockPanel · Grid
RAD StudioVCL · FMXTMainMenu · TPanel · TLayout

VCL·FMX에서 기존 폼 속성의 조회·승인·저장·재조회를 확인했습니다. 미저장 변경과 읽기 전용 상태를 구분해 안내합니다. 컨트롤 생성·삭제와 이벤트 처리기는 승인된 소스 편집이 필요합니다.

작업과 데이터

프로젝트를 중심으로,
명확한 연결과 변경 범위.

IDE와 Core는 현재 사용자 전용 Named Pipe로 인증합니다. 대화는 로컬에 저장됩니다. 모델 사용 시 질문·코드·도구 결과는 설정한 AI 공급자로 전송될 수 있습니다.
