IDE 하나 + OMP + 사용할 AI 연결 하나부터 준비하세요. OMP는 PiAgent의 요청을 AI 모델에 전달하고 실행하는 프로그램입니다. Claude Code, Codex, Grok Build, Antigravity를 전부 설치할 필요는 없습니다.

  1. 1IDE 준비Visual Studio / RAD Studio
  2. 2기본 도구WebView2 · Git
  3. 3PiAgent + OMP설치기에서 선택
  4. 4AI 연결 하나계정 / API 키 / 로컬 모델
  5. 5OMP 응답 확인모델 선택 후 간단한 질문
  6. 6IDE 첫 대화프로젝트를 열고 읽기 요청

1. 사용할 IDE 하나부터 설치하세요.

VS2022/2026 또는 RAD13.2에서 프로젝트가 열리고 빌드되는지 확인하세요. VS Code는 다른 제품이며 RAD11/12는 해당 SDK로 별도 빌드한 BPL이 필요합니다.

완료: 기존 프로젝트 빌드 성공

2. WebView2와 Git을 준비하세요.

채팅 창에는 WebView2 Evergreen Runtime이 필요합니다. 승인 파일 변경·복원에는 Git 저장소와 첫 커밋이 필요합니다. PiAgent용 Node.js / .NET runtime은 통합 설치본에 포함됩니다.

완료: 채팅 runtime 확인 · 변경할 프로젝트의 첫 커밋

3. IDE를 닫고 PiAgent를 설치하세요.

Core와 사용할 IDE 항목을 선택하세요. RAD 항목은 프로젝트 출력 대상이 아닌 IDE의 32/64-bit 구분입니다. OMP가 없으면 OMP 설치를 선택하고, 기존 OMP는 재사용합니다.

완료: 설치 완료 · 시작 메뉴의 OMP 실행

4. 아래에서 AI 연결 하나를 선택하세요.

OMP에서 /login으로 제공자 안내에 따라 인증하고 /model로 모델을 선택하세요. PiAgent 계정 탭에서 터미널 인증을 요청하면 OMP에서 진행하세요. 별도 앱 로그인과 OMP 인증은 따로 확인합니다.

완료: 사용 가능한 모델 하나 선택

5. 먼저 OMP에서 답변을 받아보세요.

파일을 바꾸지 않고 한 문장으로 인사해 달라고 요청하세요. 실패하면 계정·모델·한도·네트워크 또는 로컬 서버를 먼저 확인하세요. 처음부터 여러 모델 역할이나 플러그인을 구성할 필요는 없습니다.

완료: 정상 답변 수신 · 테스트 대화 종료

6. 프로젝트를 열고 PiAgent를 시작하세요.

VS: Tools → PiAgent: Open Chat. RAD: View/Tools → PiAgent. 연결·프로젝트·모델을 확인하고 “파일을 바꾸지 말고 프로젝트 구조를 설명해 주세요”라고 요청하세요. 성공 후 작은 변경과 승인으로 진행하세요.

완료: IDE에서 올바른 프로젝트로 첫 답변

어떤 AI를 사용할지 하나부터 선택하세요.

설치 · 로그인 · 모델 선택은 각각 확인해야 합니다. 구독과 API 과금은 별개일 수 있습니다. 계정의 접근 권한과 OMP 버전에 따라 선택지가 달라집니다.

OMP 명령을 찾지 못하면 시작 메뉴의 OMP 실행 바로가기를 사용하세요. PiAgent가 설치한 OMP는 전역 PATH에 없을 수 있습니다.

막혔을 때 어디부터 확인하나요?
  • IDE 선택 불가 → IDE 설치와 지원 버전 확인. 빈 채팅 창 → WebView2 확인.
  • OMP 응답 실패 → 계정·모델·한도·네트워크 또는 Ollama 서버 확인.
  • OMP는 정상, PiAgent 연결 실패 → Core/OMP 경로와 IDE 등록 확인. 변경만 차단 → Git·승인·미저장 폼 확인.
