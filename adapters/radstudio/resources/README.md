# Icon resources

These original RADAgent assets were copied unchanged from the local reference repository,
at the user's request: `RADAgent.ico`, `MenuIcon-16.png`, `MenuIcon-32.png`.
They supply the PiAgent chat window icon and the View / Tools menu icons, with two DPI sizes.
The reference repository is not modified. Windows SDK `rc.exe` compiles `PiAgentIcons.rc`;
the generated `.res` is embedded in the BPL before signing.
