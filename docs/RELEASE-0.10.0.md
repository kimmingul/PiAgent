# PiAgent 0.10.0 — Visual Studio IDE 도구와 코드 제안

**한국어** · [English](RELEASE-0.10.0.en.md) · [사용 안내](VS-INTELLIGENCE.md)

Visual Studio 2026과 VS2022 17.14 이상에서 다음 다섯 단계를 제공합니다.

1. 솔루션·프로젝트·미저장 문맥, 오류 목록·컴파일 진단, Roslyn C#/VB 정의·참조·호출자 탐색.
2. VS 빌드와 선택 테스트 프로젝트의 검색·필터 실행, TRX 실패 결과. 실행 테스트가 없거나 결과 파일이 없으면 성공으로 표시하지 않습니다.
3. 중단점과 디버거 시작·계속·단계 실행·종료, 중단 상태의 호출 스택·지역 변수와 승인된 식 평가.
4. VS 기본 제안 서비스의 인라인 회색 텍스트, Tab 수락, Esc 닫기, Ctrl+Z 실행 취소.
5. 현재 문서의 다음 수정 미리보기·수락과 디버깅 중인 modern .NET 프로세스의 CPU 상위 메서드 측정.

자동 제안은 기본으로 꺼져 있습니다. Tools → Options → PiAgent → Editor Suggestions에서 설정합니다. 편집기 요청은 도구와 세션 저장을 끈 별도 OMP에서 실행되어 채팅 세션을 점유하지 않습니다. 오래된 문서 응답과 이전 요청은 버리며 UTF-16 범위를 검사합니다. 한글 조합 중에는 요청과 수락을 피합니다.

빌드·테스트·디버거 변경·프로파일링은 작업별 승인과 취소를 지원합니다. 계획/읽기 모드에서는 실행하지 않습니다. VS 내부 읽기 도구에도 프로젝트 경로 제한을 적용합니다. VS2022 17.14 미만은 설치 대상에서 제외합니다.

실제 VS2026 검증 중 발견한 메뉴 포커스 문제와 다음 수정 위치 이동 시 제안이 취소되는 문제를 수정했습니다. 채팅과 편집기 요청을 분리하고 빠른 요청 교체 시 취소 오류를 일관되게 처리합니다.

지원 범위와 검증 기록은 [VS 도구 안내](VS-INTELLIGENCE.md)와 [검증 기록](VALIDATION.md)을 참고하세요. C++ 의미 분석, Test Explorer 상태 조작, native/.NET Framework 프로파일링, 메모리 분석, 여러 문서에 걸친 다음 수정은 포함하지 않습니다. CPU 측정에는 공식 `dotnet-trace` 도구가 별도로 필요합니다. RAD Studio의 기존 VCL/FMX 기능은 유지합니다.
