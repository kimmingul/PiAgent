# PiAgent 0.11.2 — scoped prerelease

**[한국어](RELEASE-0.11.2.md)** · English · [Usage guide](IDE-AGENT-INTEGRATION.en.md) · [Validation history](VALIDATION.md)

Version 0.11.2 improves test evidence retention and RAD diagnostic freshness after 0.11.1. Scoped results for the signed VSIX, RAD Win32/Win64 BPLs and final signed installer are recorded in the [validation history](VALIDATION.md). The final repacked installer passed its own checks; its distributed bytes are identified by the release `.exe.sha256`. Documents inside the installer are a packaging-time snapshot; post-packaging verification results were added to this repository and the documentation ZIP. The unsigned four-hour results below do not automatically validate new signed bytes.

- VS multi-target VSTest runs retain distinct TRX files per framework and aggregate their results. An incomplete report count relative to the expected frameworks is rejected. This does not independently verify each report's framework identity. A separate net9/net10 fixture produced one failure and one pass with CLI exit code 1 when its failure condition was on, and two passes with exit code 0 when it was off. This was not a model code-repair test.
- RAD external Delphi build diagnostics are invalidated by a subsequent native or external build. The build request ID and log hash are recorded; cached rows are rejected if reported source or project bytes change or an IDE buffer is dirty. `mayBeStale` remains because compiler-time bytes and every dependency are not verified. Investigation of the RAD 13.2 public SDK found no API to enumerate or subscribe to existing compiler message rows; the explicit external-build log remains the source.

The full 0.11.2 Core regression ran **226 tests: 225 PASS, zero failures and one optional native RAD skip**; Win32/Win64 adapter integration passed **18/18 combined**, and the VS native console passed **95** checks. The signed VSIX passed isolated VS2026 WPF **8/8**, archived UI **104/104 hash match**, and actual archived-UI WebView **93 PASS**. Signed RAD13.2 Win32/Win64 BPLs each passed VCL designer **11/11** and native SDK **28/28**, plus FMX designer **9/9** and native SDK **28/28**. The final signed installer passed **1,065 payload hashes** and x64/ARM64 runtime, policy and language checks. These results do not establish normal-profile installation/recovery or model-led repair of arbitrary projects.

Automated isolated IDE observation/build **240-minute runs passed 3/3** on unsigned working-tree binaries for RAD13.2 Win64 VCL/FMX and VS2026 WPF. Each cleared 14,400 seconds by both UTC and monotonic clocks, with 2,867 samples, 24 builds and zero errors. Original receipts, binary hashes and unchanged verifier results are recorded in the local `artifacts/ide-soak-20261010/verified-results.json` and [validation history](VALIDATION.md). This is not four hours of human use, model inference/repair performance, normal-profile IDE use, or a long-duration test of the **signed 0.11.2 package**. The prior 0.10.0 shortfall and signed 0.11.1 package record remain in the validation history.

See the [installation guide](INSTALLATION.en.md) for scope. Matched Copilot/KAI measurements have not been performed, and no superiority claim is made. Neither all M0–M6 exit criteria nor complete automated repair of arbitrary projects is claimed.
