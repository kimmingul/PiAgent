# PiAgent 0.9.19 — 한국어와 영어

**한국어** · [English](RELEASE-0.9.19.en.md) · [문서](README.md)

2026-10-08의 서명 사전 릴리즈. [설치파일·SHA-256](https://github.com/kimmingul/PiAgent/releases/tag/v0.9.19).

설정의 **표시 → 언어**에서 한국어/영어를 선택하고 현재 프로젝트의 비공개 설정에 저장한다.
기본값 `자동`은 한국어 Windows에서 한국어, 그 외에는 영어다. VS/RAD가 Windows 표시 언어를
UI에 전달하므로 WebView의 브라우저 언어가 달라도 시스템 기본값을 정확히 적용한다.
기존 일본어·독일어·프랑스어 선택도 유지하며 PiAgent 추가 화면은 영어로 대체 표시한다.

설정 탭, 계정과 인증 버튼, 모델 역할·프리셋, 실행 제어, Git 관리, 저장 세션, 승인 안내의
고정 한국어 문구를 번역한다. 언어 적용 시 열린 화면의 레이블을 갱신하고 현재 탭,
미전송 인증 입력과 채팅 초안, 승인 상태를 유지한다. 늦게 도착한 시작 번역이 저장된 언어를
덮어쓰지 않도록 요청 순서를 확인한다. 알려진 PiAgent 안내만 번역하며 모델 답변, 코드,
외부 도구 원문과 인증 데이터는 자동 번역하지 않는다.

설치프로그램은 오른쪽 위에 한국어/English 선택을 제공한다. 기본값도 한국어 Windows는
한국어, 나머지는 영어다. 설치·제거 안내, 진행 상태, PiAgent 오류와 바로가기를 번역한다.
제거 실행에 선택한 언어를 전달하고, 언어를 바꿔 업데이트해도 PiAgent 바로가기가 중복되지 않는다.
`--language auto|ko|en`은 UI, 진단, 무인 설치와 제거 실행에 사용할 수 있다.

홈페이지는 `?lang=ko|en` 직접 링크와 선택 저장을 지원한다. 본문·메타 설명·접근성 레이블·
사용/설치 문서 링크를 함께 바꾼다. 저장소가 차단되어도 언어 선택이 작동한다.
README, 설치 가이드, 통합 설치, RAD 디자이너 진단과 최신 릴리즈 안내에 한국어/영어 경로를 제공하고
배포 payload에도 주요 언어별 문서를 포함한다. 과거 개발·진단 기록은 원문으로 유지할 수 있다.

검증 기록은 [언어 지원](LOCALIZATION.md)에 정리한다. 실제 VCL·FMX의 기존 속성 변경 검증과
폼 디자이너 지원 범위는 [0.9.18](RELEASE-0.9.18.md)을 그대로 유지한다.
언어 기능 추가가 VS2022 또는 RAD32의 미완료 실사용 검증을 대신하지 않는다.
