# PiAgent 0.11.2 — 범위를 명시한 사전 릴리즈

**한국어** · [English](RELEASE-0.11.2.en.md) · [사용 안내](IDE-AGENT-INTEGRATION.md) · [검증 이력](VALIDATION.md)

0.11.2는 0.11.1 이후의 테스트 증거 보존과 RAD 진단 신선도 처리를 보강한다. 서명된 VSIX·RAD Win32/Win64 BPL과 최종 서명 설치파일의 제한된 검증 결과는 [검증 이력](VALIDATION.md)에 기록했다. 최종 재포장 설치파일도 별도 검사를 통과했으며, 배포 바이트의 해시는 릴리즈 `.exe.sha256`을 따른다. 설치파일 내부 문서는 포장 시점의 기록이며, 포장 후 최종 검사 결과는 이 저장소와 문서 ZIP에 추가했다. 아래의 미서명 4시간 시험은 새 서명 바이트를 자동으로 검증하지 않는다.

- VS VSTest 다중 대상 프레임워크 실행은 framework별 TRX가 덮어쓰이지 않도록 별도 파일로 저장하고 결과를 합산한다. 예상 framework 수와 보고서 수가 맞지 않으면 완료로 처리하지 않는다. 각 보고서의 framework 신원을 독립적으로 검증하는 기능은 아니다. 별도 net9/net10 fixture에서 실패 조건을 켰을 때 1 실패·1 성공과 CLI 종료 코드 1, 껐을 때 2 성공과 종료 코드 0을 확인했다. 이는 모델의 코드 수정·재시험 성공률 시험이 아니다.
- RAD의 외부 Delphi 빌드 진단은 새 네이티브/외부 빌드 때 무효화한다. 빌드 요청 ID와 로그 해시를 기록하고 보고된 파일·프로젝트 바이트가 바뀌거나 IDE 버퍼가 수정 상태이면 보관된 진단을 거절한다. 빌드 당시 모든 입력·의존성은 입증할 수 없으므로 `mayBeStale` 표시는 유지한다. RAD 13.2 공개 SDK에서 현재 컴파일러 메시지 행의 열거/구독 API를 찾지 못했으며, 외부 빌드 로그를 명시적으로 사용한다.

0.11.2 Core 전체 회귀는 **226개 중 225 PASS·실패 0·선택 native RAD 1 skip**, Win32/Win64 어댑터 통합은 합계 **18/18**, VS 네이티브 콘솔은 **95 PASS**다. 서명된 VSIX는 격리 VS2026 WPF **8/8**, 보관된 UI **104/104 해시 일치**, 실제 보관 UI WebView **93 PASS**를 통과했다. 서명된 RAD13.2 Win32/Win64 BPL은 각 아키텍처에서 VCL 디자이너 **11/11**·네이티브 SDK **28/28**, FMX 디자이너 **9/9**·네이티브 SDK **28/28**을 통과했다. 최종 서명 설치파일은 **1,065개 payload 해시**, x64/ARM64 runtime·정책·언어 검사를 통과했다. 이 결과를 일반 IDE 프로필 설치·복구나 임의 프로젝트의 모델 주도 수리로 확대하지 않는다.

미서명 작업 트리의 격리 RAD13.2 Win64 VCL/FMX와 VS2026 WPF에서 자동 IDE 관측·빌드 **240분 시험 3/3 PASS**를 기록했다. 각 시험은 UTC와 단조 시간 모두 14,400초를 넘었고, 표본 2,867개·빌드 24회·오류 0건이었다. 원본 영수증·바이너리 해시와 변경하지 않은 검증기의 결과는 로컬 `artifacts/ide-soak-20261010/verified-results.json` 및 [검증 이력](VALIDATION.md)에 기록했다. 이는 사람의 4시간 사용, 모델 추론·수리 성능, 일반 IDE 프로필 또는 **서명된 0.11.2 패키지**의 장시간 검증은 아니다. 이전 0.10.0의 미달 시험과 0.11.1의 서명 패키지 기록은 검증 이력에 그대로 보존한다.

설치 범위는 [설치 안내](INSTALLATION.md)를 따른다. Copilot/KAI와 조건을 맞춘 실측 비교는 수행하지 않았으며 우위 주장은 없다. M0–M6 전체 완료 또는 임의 프로젝트의 완결된 자동 수리도 주장하지 않는다.
