4. Not included, used when installed by the user
   - oh-my-pi (omp), MIT License, https://github.com/can1357/oh-my-pi
     RAD Agent does not ship omp. When omp is missing, the setup offers to download the latest
     official release for the PC's processor (x64 or ARM64) from GitHub, checked against its
     published SHA-256, to %LOCALAPPDATA%\omp.
   - clangd, part of the LLVM project, Apache License 2.0 with LLVM Exceptions,
     https://github.com/clangd/clangd - downloaded only when the user asks for it in Settings.
   - Microsoft Edge WebView2 Runtime, provided by Windows.
